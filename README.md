# 人生ものさし年表

生年月日を入力すると、自分の「いま」をいろんなものさしで測って表示するWebアプリです。

公開URL: https://gearbox00.github.io/life-timeline/

## 使い方

`index.html` をダブルクリックしてブラウザで開くだけで動きます。
(サーバーもインストールも不要です)

生年月日は「年・月・日」を分けて入れます。年は直接打ち込めるので、
古い年でも延々スクロールする必要はありません。月に合わせて日の選択肢が変わります
(2月なら28日まで、うるう年なら29日まで)。

一度入力した生年月日と、最後に見ていたタブはブラウザに保存され、次に開いたときは自動で表示されます。

## 画面の構成

年齢の見出しとシェアボタンは常に表示され、それ以外は5つのタブに分かれています。

| タブ | 中身 |
|---|---|
| わたし | 人生の見取り図 / 基本データ / 記念日カウンター / 体の数字 / 学年・入学年早見 |
| 時代 | タイムカプセル / 自分史年表 / 人生ミラー |
| くらべる | 歴史上の人物 / 創作キャラの同世代 / 同じ誕生日の有名人 / 同学年の有名人 / 家族・友だちとくらべる |
| ものさし | 人生時計 / 体感時間 / 地球100歳 / 惑星年齢 / 動物にたとえると |
| これから | これからの楽しみ年表 / あと何回カレンダー |

右上のボタンで、明るい表示と暗い表示(ダークモード)を切り替えられます。
一度も押していないときは、パソコンやスマホ本体の設定に自動で合わせます。

## 記念日をカレンダーに登録

「わたし」タブの記念日カウンターにある
「これからの記念日をカレンダーに登録」を押すと `kinenbi.ics` が保存されます。
このファイルを開くと、スマホやパソコンのカレンダーに記念日がまとめて登録されます
(前日にお知らせが出ます)。

すでに過ぎた記念日は書き出されません。

## リンクで共有

「リンクをコピー」を押すと、生年月日入りのURLができます。

```
https://gearbox00.github.io/life-timeline/?b=1975-08-20
```

相手がこのリンクを開くと、同じ結果がそのまま表示されます。
「くらべる」で相手を入力してあれば `&o=1952-02-11` も付き、比較結果まで再現されます。

リンクを開いた人の「前回入力した生年月日」は上書きされません。
なお **URLには生年月日が含まれます**。誰に送るかはご注意ください。

## 印刷

画面下の「全部まとめて印刷」を押すと、**タブで隠れている分もすべて**紙に出ます。
折りたたんである部分も自動で開き、暗い表示にしていても白い紙に印刷されます。
ボタンやタブなどの操作部品は印刷されません。

タブを増やしたいときは `index.html` のタブボタン(`data-tab` の値)と、対応する
`<div class="tabpanel" id="panel-○○">` を追加します。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組み |
| `style.css` | 見た目のデザイン |
| `app.js` | 年齢などの計算と表示のプログラム |
| `data.js` | **データ集(ここに追記して育てるファイル)** |

## データの増やし方

`data.js` をメモ帳などで開いて、同じ形式の行をコピーして追記するだけです。

### 歴史上の人物を増やす

```js
{
  name: "人物名", born: 生まれた年,
  events: [
    { age: 年齢, text: "その年齢でしたこと" },
  ],
},
```

### 創作キャラを増やす

```js
{ name: "キャラ名", work: "作品名", age: 年齢, note: "補足(省略可)" },
```

### 地球史の出来事を増やす

```js
{ yearsAgo: 何年前か, label: "出来事" },
```

### 有名人を増やす(「同じ誕生日」と「同学年」の両方に反映されます)

```js
{ name: "名前", field: "分野", y: 年, m: 月, d: 日 },
```

### 未来のイベントを増やす

```js
{ year: 西暦, month: 月(省略可), label: "出来事" },
```

### 生まれた年のタイムカプセルを増やす(1945年〜2025年は登録済み)

```js
西暦: { news: "出来事", culture: "流行・文化", born: "同い年のモノ(省略可)" },
```

## 今の機能

- 基本データ(年齢・和暦・干支・生きた日数/秒数)
- 人生時計(80年を24時間に換算)
- 歴史上の人物の「同じ年齢のとき」
- 創作キャラの「同世代」
- 地球100歳スケール
- 人生ミラー(生きた長さだけ過去に遡る)
- 惑星年齢/動物年齢換算
- 記念日カウンター(1万日目・10億秒など)
- 体の数字(心拍・呼吸ほか)
- ジャネーの法則(体感時間)
- 学年・入学年早見
- 生まれた日のタイムカプセル(その年の出来事・流行・同い年のモノ・物価)
- これからの楽しみ年表(未来のイベントを「あなたが何歳の年」で表示)
- あと何回カレンダー(桜・オリンピック・満月など/折りたたみ表示)
- くらべる(家族・友だちの生年月日との比較)
- シェア(結果を画像で保存/テキストでコピー)
- 人生の見取り図(生まれてから80歳までを1本の帯で表示。くらべた相手も並べられる)
- 同じ誕生日の有名人 / 同学年の有名人(早生まれも計算に入れています)
- ダークモード
- 印刷(全タブをまとめて1つの紙資料として出力)
- リンクで共有(URLに生年月日を入れて、同じ結果を相手に見せる)
- 記念日のカレンダー登録(.icsファイルの書き出し)

## データについて

有名人の生年月日は一般に知られている情報をもとにしていますが、
まちがいを見つけたら `data.js` を直接直してください。
