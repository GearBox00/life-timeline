# 人生ものさし年表

生年月日を入力すると、自分の「いま」をいろんなものさしで測って表示するWebアプリです。

## 使い方

`index.html` をダブルクリックしてブラウザで開くだけで動きます。
(サーバーもインストールも不要です)

一度入力した生年月日はブラウザに保存され、次に開いたときは自動で表示されます。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組み |
| `style.css` | 見た目のデザイン |
| `app.js` | 年齢などの計算と表示のプログラム |
| `data.js` | **データ集(ここに追記して育てるファイル)** |

## データの増やし方

`data.js` をメモ帳などで開いて、同じ形式の行をコピーして追記するだけです。

### 歴史上の人物を増やす

```js
{
  name: "人物名", born: 生まれた年,
  events: [
    { age: 年齢, text: "その年齢でしたこと" },
  ],
},
```

### 創作キャラを増やす

```js
{ name: "キャラ名", work: "作品名", age: 年齢, note: "補足(省略可)" },
```

### 地球史の出来事を増やす

```js
{ yearsAgo: 何年前か, label: "出来事" },
```

### 未来のイベントを増やす

```js
{ year: 西暦, month: 月(省略可), label: "出来事" },
```

### 生まれた年のタイムカプセルを増やす(1945年〜2025年は登録済み)

```js
西暦: { news: "出来事", culture: "流行・文化", born: "同い年のモノ(省略可)" },
```

## 今の機能

- 基本データ(年齢・和暦・干支・生きた日数/秒数)
- 人生時計(80年を24時間に換算)
- 歴史上の人物の「同じ年齢のとき」
- 創作キャラの「同世代」
- 地球100歳スケール
- 人生ミラー(生きた長さだけ過去に遡る)
- 惑星年齢/動物年齢換算
- 記念日カウンター(1万日目・10億秒など)
- 体の数字(心拍・呼吸ほか)
- ジャネーの法則(体感時間)
- 学年・入学年早見
- 生まれた日のタイムカプセル(その年の出来事・流行・同い年のモノ・物価)
- これからの楽しみ年表(未来のイベントを「あなたが何歳の年」で表示)
- あと何回カレンダー(桜・オリンピック・満月など/折りたたみ表示)
- くらべる(家族・友だちの生年月日との比較)
- シェア(結果を画像で保存/テキストでコピー)
